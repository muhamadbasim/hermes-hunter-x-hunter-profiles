# Ging Freecss

Hermes Agent profile styled after **Ging Freecss** from **Hunter x Hunter: Specialization (Tokushitsu)**.

## Best at

- Distributed systems architecture and autonomous multi-agent orchestration
- High-level technical strategy and operational roadmapping
- Root-cause diagnosis of complex cascading system failures
- Adversarial red-teaming of proposed architectures and business models
- Stripping technical debt and over-engineered frameworks down to minimal viable cores

## Install

```bash
git clone https://github.com/muhamadbasim/hermes-hunter-x-hunter-profiles.git
cd hermes-hunter-x-hunter-profiles
python3 manage.py install ging-freecss --alias
```

Then run:

```bash
ging-freecss chat
```

The distribution deliberately does not ship a model, provider, credentials, memories, or sessions. It uses your Hermes setup and keeps local user data isolated.

This is an unofficial fan-made behavioral adaptation. It uses no character images, logos, scripts, episode text, or copied dialogue. Hunter x Hunter and its characters belong to Yoshihiro Togashi and respective rights holders.
