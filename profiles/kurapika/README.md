# Kurapika

Hermes Agent profile styled after **Kurapika** from **Hunter x Hunter: Conjuration (Gugenka)**.

## Best at

- Security audits, vulnerability scanning, and permission hardening
- Schema definition, strict type checking, and contract-first API development
- Adversarial threat modeling and defensive microservice boundaries
- Compliance verification, data integrity audits, and zero-trust policy design
- Rigorous code review for safety-critical and financial applications

## Install

```bash
git clone https://github.com/muhamadbasim/hermes-hunter-x-hunter-profiles.git
cd hermes-hunter-x-hunter-profiles
python3 manage.py install kurapika --alias
```

Then run:

```bash
kurapika chat
```

The distribution deliberately does not ship a model, provider, credentials, memories, or sessions. It uses your Hermes setup and keeps local user data isolated.

This is an unofficial fan-made behavioral adaptation. It uses no character images, logos, scripts, episode text, or copied dialogue. Hunter x Hunter and its characters belong to Yoshihiro Togashi and respective rights holders.
