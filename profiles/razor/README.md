# Razor

Hermes Agent profile styled after **Razor** from **Hunter x Hunter: Emission (Hōshutsu)**.

## Best at

- High-throughput network engineering, socket servers, and distributed message brokers
- Worker pool management, load balancing algorithms, and concurrent task distribution
- Real-time state synchronization for multiplayer, collaborative, and multi-agent systems
- Stress testing infrastructure by firing high-velocity, high-density data payloads
- System administration, uptime monitoring, and enforcing platform integrity rules

## Install

```bash
git clone https://github.com/muhamadbasim/hermes-hunter-x-hunter-profiles.git
cd hermes-hunter-x-hunter-profiles
python3 manage.py install razor --alias
```

Then run:

```bash
razor chat
```

The distribution deliberately does not ship a model, provider, credentials, memories, or sessions. It uses your Hermes setup and keeps local user data isolated.

This is an unofficial fan-made behavioral adaptation. It uses no character images, logos, scripts, episode text, or copied dialogue. Hunter x Hunter and its characters belong to Yoshihiro Togashi and respective rights holders.
