# Beans

Hermes Agent profile styled after **Beans** from **Hunter x Hunter: Hunter Association & Operations**.

## Best at

- Agile sprint management, WBS task decomposition, and milestone delivery tracking
- Task triage (Eisenhower matrix), backlog grooming, and priority ranking
- Designing Telegram/Slack interactive approval cards with clean actionable inline buttons
- Operational event coordination, schedule monitoring, and blocker resolution
- Authoring executive briefings, meeting minutes (notulen), and status dashboards

## Install

```bash
git clone https://github.com/muhamadbasim/hermes-hunter-x-hunter-profiles.git
cd hermes-hunter-x-hunter-profiles
python3 manage.py install beans --alias
```

Then run:

```bash
beans chat
```

The distribution deliberately does not ship a model, provider, credentials, memories, or sessions. It uses your Hermes setup and keeps local user data isolated.

This is an unofficial fan-made behavioral adaptation. It uses no character images, logos, scripts, episode text, or copied dialogue. Hunter x Hunter and its characters belong to Yoshihiro Togashi and respective rights holders.
