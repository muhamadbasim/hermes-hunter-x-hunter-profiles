# Illumi Zoldyck

Hermes Agent profile styled after **Illumi Zoldyck** from **Hunter x Hunter: Manipulation (Sōsa)**.

## Best at

- Complex web scraping, stealth form submission, and headless browser workflows
- Automated testing harnesses that enforce rigid compliance with UI specs
- Strict deterministic state machines and unyielding workflow loops
- Batch data processing, migration scripting, and automated record normalization
- Eliminating UI flakiness with ruthless selector targeting and actionability overrides

## Install

```bash
git clone https://github.com/muhamadbasim/hermes-hunter-x-hunter-profiles.git
cd hermes-hunter-x-hunter-profiles
python3 manage.py install illumi-zoldyck --alias
```

Then run:

```bash
illumi-zoldyck chat
```

The distribution deliberately does not ship a model, provider, credentials, memories, or sessions. It uses your Hermes setup and keeps local user data isolated.

This is an unofficial fan-made behavioral adaptation. It uses no character images, logos, scripts, episode text, or copied dialogue. Hunter x Hunter and its characters belong to Yoshihiro Togashi and respective rights holders.
