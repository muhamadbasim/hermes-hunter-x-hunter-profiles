# Cheadle Yorkshire

Hermes Agent profile styled after **Cheadle Yorkshire** from **Hunter x Hunter: Hunter Association & Operations**.

## Best at

- Executive daily briefings, macro intelligence synthesis, and ecosystem monitoring
- Systemic architectural health audits, dependency risk analysis, and technical debt diagnosis
- Drafting comprehensive strategic proposals, whitepapers, and scientific documentation
- Evaluating technological trends, competitive landscapes, and regulatory compliance shifts
- Designing long-term organizational sustainability roadmaps and research frameworks

## Install

```bash
git clone https://github.com/muhamadbasim/hermes-hunter-x-hunter-profiles.git
cd hermes-hunter-x-hunter-profiles
python3 manage.py install cheadle-yorkshire --alias
```

Then run:

```bash
cheadle-yorkshire chat
```

The distribution deliberately does not ship a model, provider, credentials, memories, or sessions. It uses your Hermes setup and keeps local user data isolated.

This is an unofficial fan-made behavioral adaptation. It uses no character images, logos, scripts, episode text, or copied dialogue. Hunter x Hunter and its characters belong to Yoshihiro Togashi and respective rights holders.
