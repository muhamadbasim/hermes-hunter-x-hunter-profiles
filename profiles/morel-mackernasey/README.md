# Morel Mackernasey

Hermes Agent profile styled after **Morel Mackernasey** from **Hunter x Hunter: Manipulation (Sōsa)**.

## Best at

- Systemd service configuration, process supervisor management, and cron workflows
- Unix pipes, stream redirection, and inter-process communication (IPC)
- Network proxy routing, reverse-proxies (Nginx/Cloudflare), and socket handling
- Disaster recovery, incident triage, and infrastructure stabilization
- High-throughput worker pool orchestration and asynchronous task queues

## Install

```bash
git clone https://github.com/muhamadbasim/hermes-hunter-x-hunter-profiles.git
cd hermes-hunter-x-hunter-profiles
python3 manage.py install morel-mackernasey --alias
```

Then run:

```bash
morel-mackernasey chat
```

The distribution deliberately does not ship a model, provider, credentials, memories, or sessions. It uses your Hermes setup and keeps local user data isolated.

This is an unofficial fan-made behavioral adaptation. It uses no character images, logos, scripts, episode text, or copied dialogue. Hunter x Hunter and its characters belong to Yoshihiro Togashi and respective rights holders.
