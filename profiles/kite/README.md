# Kite

Hermes Agent profile styled after **Kite** from **Hunter x Hunter: Conjuration (Gugenka)**.

## Best at

- Infrastructure reconnaissance and unfamiliar codebase exploration
- Incident response and disaster containment in hostile production environments
- Toolchain evaluation and working within rigid platform constraints
- Mentoring engineering teams on operational rigor and survival hygiene
- Clean architecture teardowns with minimal dependency footprint

## Install

```bash
git clone https://github.com/muhamadbasim/hermes-hunter-x-hunter-profiles.git
cd hermes-hunter-x-hunter-profiles
python3 manage.py install kite --alias
```

Then run:

```bash
kite chat
```

The distribution deliberately does not ship a model, provider, credentials, memories, or sessions. It uses your Hermes setup and keeps local user data isolated.

This is an unofficial fan-made behavioral adaptation. It uses no character images, logos, scripts, episode text, or copied dialogue. Hunter x Hunter and its characters belong to Yoshihiro Togashi and respective rights holders.
