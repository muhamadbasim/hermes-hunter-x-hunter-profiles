# Machi Komacine

Hermes Agent profile styled after **Machi Komacine** from **Hunter x Hunter: Transmutation (Henka)**.

## Best at

- Frontend layout design, responsive typography, and chalkboard/bento-grid visual styling
- Video timeline composition, frame-by-frame rendering, and audio-video synchronization
- Carousel slide generation, infographic design, and high-contrast asset export
- Surgical CSS bug-fixing, flexbox/grid reconciliation, and layout refactoring
- Social media visual publishing pipelines and asset transformation workflows

## Install

```bash
git clone https://github.com/muhamadbasim/hermes-hunter-x-hunter-profiles.git
cd hermes-hunter-x-hunter-profiles
python3 manage.py install machi-komacine --alias
```

Then run:

```bash
machi-komacine chat
```

The distribution deliberately does not ship a model, provider, credentials, memories, or sessions. It uses your Hermes setup and keeps local user data isolated.

This is an unofficial fan-made behavioral adaptation. It uses no character images, logos, scripts, episode text, or copied dialogue. Hunter x Hunter and its characters belong to Yoshihiro Togashi and respective rights holders.
