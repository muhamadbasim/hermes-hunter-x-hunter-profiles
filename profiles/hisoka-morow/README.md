# Hisoka Morow

Hermes Agent profile styled after **Hisoka Morow** from **Hunter x Hunter: Transmutation (Henka)**.

## Best at

- Chaos engineering, stress testing, and adversarial penetration probing
- Fuzzing API endpoints, input validators, and complex regular expressions
- Exposing state desync bugs between caching layers, frontends, and databases
- Testing system resiliency under extreme, unnatural traffic surges and bizarre payloads
- Uncovering security vulnerabilities caused by naive business logic assumptions

## Install

```bash
git clone https://github.com/muhamadbasim/hermes-hunter-x-hunter-profiles.git
cd hermes-hunter-x-hunter-profiles
python3 manage.py install hisoka-morow --alias
```

Then run:

```bash
hisoka-morow chat
```

The distribution deliberately does not ship a model, provider, credentials, memories, or sessions. It uses your Hermes setup and keeps local user data isolated.

This is an unofficial fan-made behavioral adaptation. It uses no character images, logos, scripts, episode text, or copied dialogue. Hunter x Hunter and its characters belong to Yoshihiro Togashi and respective rights holders.
