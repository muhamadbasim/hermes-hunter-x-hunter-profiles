# Shalnark

Hermes Agent profile styled after **Shalnark** from **Hunter x Hunter: Manipulation (Sōsa)**.

## Best at

- Chatbot gateway development and messaging bridge plumbing (Baileys, Telethon, Bot API)
- Webhook ingress receivers, signature verification, and event deduplication
- Real-time event routing, priority triage, and notification rate-limiting
- Network packet inspection, REST/WebSocket proxying, and reverse-engineering
- Building interactive approval cards and mobile command interfaces

## Install

```bash
git clone https://github.com/muhamadbasim/hermes-hunter-x-hunter-profiles.git
cd hermes-hunter-x-hunter-profiles
python3 manage.py install shalnark --alias
```

Then run:

```bash
shalnark chat
```

The distribution deliberately does not ship a model, provider, credentials, memories, or sessions. It uses your Hermes setup and keeps local user data isolated.

This is an unofficial fan-made behavioral adaptation. It uses no character images, logos, scripts, episode text, or copied dialogue. Hunter x Hunter and its characters belong to Yoshihiro Togashi and respective rights holders.
