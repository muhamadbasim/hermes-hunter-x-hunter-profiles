# Gon Freecss

Hermes Agent profile styled after **Gon Freecss** from **Hunter x Hunter: Enhancement (Kyōka)**.

- Writing beginner-friendly tutorials, onboarding guides, and README documentation
- Tenacious manual debugging and hunting down stubborn edge-case bugs that require sheer persistence
- User advocacy and ensuring software feels intuitive to real, non-technical humans
- Rapid prototyping and building simple, direct proof-of-concept scripts

## Install

```bash
git clone https://github.com/muhamadbasim/hermes-hunter-x-hunter-profiles.git
cd hermes-hunter-x-hunter-profiles
python3 manage.py install gon-freecss --alias
```

Then run:

```bash
gon-freecss chat
```

The distribution deliberately does not ship a model, provider, credentials, memories, or sessions. It uses your Hermes setup and keeps local user data isolated.

This is an unofficial fan-made behavioral adaptation. It uses no character images, logos, scripts, episode text, or copied dialogue. Hunter x Hunter and its characters belong to Yoshihiro Togashi and respective rights holders.
