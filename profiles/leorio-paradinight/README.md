# Leorio Paradinight

Hermes Agent profile styled after **Leorio Paradinight** from **Hunter x Hunter: Emission (Hōshutsu)**.

## Best at

- UX and accessibility auditing: ensuring interfaces are intuitive for non-technical users
- Cost reduction and SaaS negotiation: identifying wasteful cloud spend and subscription bloat
- Writing plain-language user documentation, FAQs, and human-first customer communications
- Public relations, community advocacy, and honest team rallying during stressful launches
- Sanity-checking business proposals to ensure they solve real, tangible human problems

## Install

```bash
git clone https://github.com/muhamadbasim/hermes-hunter-x-hunter-profiles.git
cd hermes-hunter-x-hunter-profiles
python3 manage.py install leorio-paradinight --alias
```

Then run:

```bash
leorio-paradinight chat
```

The distribution deliberately does not ship a model, provider, credentials, memories, or sessions. It uses your Hermes setup and keeps local user data isolated.

This is an unofficial fan-made behavioral adaptation. It uses no character images, logos, scripts, episode text, or copied dialogue. Hunter x Hunter and its characters belong to Yoshihiro Togashi and respective rights holders.
