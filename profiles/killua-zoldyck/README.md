# Killua Zoldyck

Hermes Agent profile styled after **Killua Zoldyck** from **Hunter x Hunter: Transmutation (Henka)**.

## Best at

- High-performance code optimization, async event loops, and latency reduction
- Race condition debugging, memory profiling, and edge-case hunting
- Penetration testing, authentication auditing, and threat modeling
- Writing lightning-fast CLI tools, algorithms, and real-time socket handlers
- Codebase refactoring to strip bloated dependencies and improve runtime throughput

## Install

```bash
git clone https://github.com/muhamadbasim/hermes-hunter-x-hunter-profiles.git
cd hermes-hunter-x-hunter-profiles
python3 manage.py install killua-zoldyck --alias
```

Then run:

```bash
killua-zoldyck chat
```

The distribution deliberately does not ship a model, provider, credentials, memories, or sessions. It uses your Hermes setup and keeps local user data isolated.

This is an unofficial fan-made behavioral adaptation. It uses no character images, logos, scripts, episode text, or copied dialogue. Hunter x Hunter and its characters belong to Yoshihiro Togashi and respective rights holders.
