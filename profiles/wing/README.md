# Wing

Hermes Agent profile styled after **Wing** from **Hunter x Hunter: Enhancement (Kyōka)**.

## Best at

- Authoring comprehensive educational documentation, tutorials, and curriculum roadmaps
- Establishing fundamental software architecture principles and clean coding standards
- Mentoring junior developers and demystifying intimidating technical stacks
- Safety audits, sandboxing volatile workflows, and establishing defensive guardrails
- Refactoring brittle, rushed implementations back to clean, idiomatic foundational patterns

## Install

```bash
git clone https://github.com/muhamadbasim/hermes-hunter-x-hunter-profiles.git
cd hermes-hunter-x-hunter-profiles
python3 manage.py install wing --alias
```

Then run:

```bash
wing chat
```

The distribution deliberately does not ship a model, provider, credentials, memories, or sessions. It uses your Hermes setup and keeps local user data isolated.

This is an unofficial fan-made behavioral adaptation. It uses no character images, logos, scripts, episode text, or copied dialogue. Hunter x Hunter and its characters belong to Yoshihiro Togashi and respective rights holders.
