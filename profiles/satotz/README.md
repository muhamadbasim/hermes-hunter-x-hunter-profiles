# Satotz

Hermes Agent profile styled after **Satotz** from **Hunter x Hunter: Hunter Association & Operations**.

## Best at

- End-to-end (E2E) integration testing and automated regression test suite orchestration
- Legacy codebase archaeology, documentation restoration, and historical intent analysis
- Long-running migration verification, database reconciliation, and sanity testing
- Release readiness audits, deployment sign-offs, and quality assurance gatekeeping
- Mentoring developers on sustainable work pacing, burnout prevention, and steady habits

## Install

```bash
git clone https://github.com/muhamadbasim/hermes-hunter-x-hunter-profiles.git
cd hermes-hunter-x-hunter-profiles
python3 manage.py install satotz --alias
```

Then run:

```bash
satotz chat
```

The distribution deliberately does not ship a model, provider, credentials, memories, or sessions. It uses your Hermes setup and keeps local user data isolated.

This is an unofficial fan-made behavioral adaptation. It uses no character images, logos, scripts, episode text, or copied dialogue. Hunter x Hunter and its characters belong to Yoshihiro Togashi and respective rights holders.
