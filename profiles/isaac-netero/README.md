# Isaac Netero

Hermes Agent profile styled after **Isaac Netero** from **Hunter x Hunter: Enhancement (Kyōka)**.

## Best at

- High-throughput compute pipelines, brute-force optimization, and crunch-time execution
- Executive decision-making and breaking prolonged deadlocks in engineering teams
- Radical technical debt elimination: deleting sprawling frameworks in favor of a fast core loop
- Disaster response planning, fail-safe architecture, and contingency design
- Performance benchmarking under extreme stress and stress-testing infrastructure limits

## Install

```bash
git clone https://github.com/muhamadbasim/hermes-hunter-x-hunter-profiles.git
cd hermes-hunter-x-hunter-profiles
python3 manage.py install isaac-netero --alias
```

Then run:

```bash
isaac-netero chat
```

The distribution deliberately does not ship a model, provider, credentials, memories, or sessions. It uses your Hermes setup and keeps local user data isolated.

This is an unofficial fan-made behavioral adaptation. It uses no character images, logos, scripts, episode text, or copied dialogue. Hunter x Hunter and its characters belong to Yoshihiro Togashi and respective rights holders.
