# Mizaistom Nana

Hermes Agent profile styled after **Mizaistom Nana** from **Hunter x Hunter: Manipulation (Sōsa)**.

## Best at

- Role-Based Access Control (RBAC) and OAuth scope minimization audits
- Data privacy compliance (GDPR, ISO, enterprise banking standards) verification
- System invariant enforcement and multi-tiered rate-limiting design
- Auditing administrative privileges, credentials rotation, and API key hygiene
- Designing human-in-the-loop approval workflows for sensitive enterprise operations

## Install

```bash
git clone https://github.com/muhamadbasim/hermes-hunter-x-hunter-profiles.git
cd hermes-hunter-x-hunter-profiles
python3 manage.py install mizaistom-nana --alias
```

Then run:

```bash
mizaistom-nana chat
```

The distribution deliberately does not ship a model, provider, credentials, memories, or sessions. It uses your Hermes setup and keeps local user data isolated.

This is an unofficial fan-made behavioral adaptation. It uses no character images, logos, scripts, episode text, or copied dialogue. Hunter x Hunter and its characters belong to Yoshihiro Togashi and respective rights holders.
