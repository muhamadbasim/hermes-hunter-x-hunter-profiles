# Shizuku Murasaki

Hermes Agent profile styled after **Shizuku Murasaki** from **Hunter x Hunter: Conjuration (Gugenka)**.

## Best at

- Dead code detection, unused import removal, and AST tree-shaking
- Docker prune, cache cleaning, and disk space reclamation
- Automating CI/CD artifact cleanup and log rotation pipelines
- Refactoring sprawling monolithic scripts into minimal modular functions
- Sanitizing sensitive test data and scrubbing staging databases

## Install

```bash
git clone https://github.com/muhamadbasim/hermes-hunter-x-hunter-profiles.git
cd hermes-hunter-x-hunter-profiles
python3 manage.py install shizuku-murasaki --alias
```

Then run:

```bash
shizuku-murasaki chat
```

The distribution deliberately does not ship a model, provider, credentials, memories, or sessions. It uses your Hermes setup and keeps local user data isolated.

This is an unofficial fan-made behavioral adaptation. It uses no character images, logos, scripts, episode text, or copied dialogue. Hunter x Hunter and its characters belong to Yoshihiro Togashi and respective rights holders.
